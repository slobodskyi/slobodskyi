### Які переваги Stable Diffusion?

#### Безкоштовний або недорогий

Stable Diffusion – інструмент з відкритим кодом, і його базові функції доступні безкоштовно.

**Почати легко, і вам не потрібно витрачати великі кошти.**

#### Підходить для будь-якого стилю (навіть NSFW)

Хочете намалювати арт в стилі аніме, реалістичний портрет або щось відверте?

Stable Diffusion впорається з будь-яким завданням.

**Інструмент гнучкий, і ви можете експериментувати без обмежень.**

#### Можна налаштовувати під себе

Чим більше ви опановуєте Stable Diffusion, тим більше можливостей для індивідуального налаштування запитів.

Ви навіть зможете «_натренувати_» інструмент під свій унікальний стиль.

Налаштування запитів схоже на гру з параметрами камери чи музичного інструмента: додали прикметник або змінили колір – і результат кардинально змінюється.

**Починайте з простих запитів і поступово ускладнюйте їх, коли відчуєте впевненість.**

#### Можна використовувати онлайн або локально

Працюйте через вебсайт або встановіть Stable Diffusion на свій комп’ютер.

Що зручніше?

- **Онлайн:** ідеально для новачків, не потрібно нічого встановлювати.
- **Локально:** для тих, хто хоче мати більше контролю та готовий розібратися в налаштуваннях.

### Stable Diffusion проти Midjourney

- **Midjourney:** простий і зручний інструмент для створення красивих зображень. Чудово підходить для тих, хто хоче швидкий результат._&#x20;Мінус:_ потребує підписки та не дозволяє створювати NSFW-контент.

Порівняймо:

- **Midjourney** – як компактна камера: просто і швидко.
- **Stable Diffusion** – як професійна камера: більше можливостей, але потрібно розібратися з налаштуваннями.

### DALL-E 3 та Adobe Firefly

- **DALL-E 3 (**[**від ChatGPT**](/ua/create/ai/chatgpt)**) та Adobe Firefly:** прості у використанні, але працюють лише за підпискою і мають суворі обмеження на NSFW-контент.
- **Stable Diffusion:** більш відкритий і часто безкоштовний, що робить його чудовим вибором для будь-яких експериментів.

Як обрати?

- Якщо хочете швидко отримати гарний стилізований арт, спробуйте **Midjourney** або **DALL-E 3**.

### Онлайн-версія: найпростіший варіант

[Diffus](https://slobo.click/diffus) – один із популярних онлайн-сервісів, який підійде тим, хто хоче швидко почати, не заглиблюючись у технічні нюанси.

#### Чому варто обрати Diffus?

- **Простота використання:** буквально кілька кліків, але треба буде розібратись що за що відповідає.
- **Не потрібні технічні знання:** все працює прямо у браузері, без складних установок.
- **Безкоштовні опції:** багато функцій доступні безкоштовно для експериментів.
- **Авторські права:** створені вами зображення залишаються вашою власністю.
- **Висока швидкість:** сервіс підійде навіть для слабших комп’ютерів, оскільки обробка відбувається на сервері.

#### Швидкий гід: як працювати з Diffus (або аналогічними платформами)

3. Натисніть «_Generate_» – і спостерігайте, як формується зображення!
4. Налаштуйте параметри – змінюйте запит або налаштування для досягнення кращого результату.

#### Що таке кредити?

Кредити – це своєрідна валюта, яку ви використовуєте для генерації зображень.

Кожен тарифний план щомісячно або щоденно надає певну кількість кредитів.

#### Як використовуються кредити?

При кожному створенні зображення через Diffus зі свого рахунку списується певна кількість кредитів.

Кількість використовуваних кредитів залежить від:

- **Використовуваної моделі:** різні моделі ШІ потребують різну кількість кредитів.
- **Роздільної здатності зображення:** зображення високої якості зазвичай потребують більше кредитів.
- **Кількості кроків обробки:** більше кроків підвищує якість, але збільшує витрати кредитів.
- **GPU:** використання виділеного GPU для пришвидшення обробки також потребує кредитів.

#### Оцінка кількості зображень

Створення високоякісних, фотореалістичних зображень потребує більше кредитів через складні налаштування.

У середньому, ви можете отримати 1–3 детальні зображення на кожні 10 кредитів.

- **Тізер-план (30 кредитів в день):** близько 10–30 зображень щодня.
- **Базовий план (3000 кредитів):** приблизно 300–900 зображень на місяць.
- **Plus-план (18000 кредитів):** близько 1800–5400 зображень на місяць.
- **Pro-план (40000 кредитів):** приблизно 4000–12000 зображень на місяць.

**Для простіших зображень або менше кроків обробки витрати можуть бути практично пропорційними 1:1.**

Встановлення Stable Diffusion на власному комп’ютері дає повний контроль над творчим процесом і можливість працювати офлайн.

**Цей варіант підійде для технічно підкованих користувачів, які не бояться експериментувати.**

Як почати:

- **GPU:** Виділена відеокарта NVIDIA з мінімум 6 ГБ відеопам’яті (наприклад, RTX 2060 або краще). GPU від AMD можуть працювати, але підтримка може бути нестабільною.

- **ЦП:** Сучасний багатоядерний процесор (наприклад, i5 або краще).
- **Накопичувач:** Не менше 10–20 ГБ вільного місця для файлів моделі та залежностей.
- **ОС:** Windows 10/11 або актуальний дистрибутив Linux (наприклад, Ubuntu).

Для macOS:

- **Apple Silicon (M1/M2):** Відмінна нативна підтримка через Metal – мінімум 8 ГБ ОЗУ (краще 16 ГБ для важких завдань).
- **Mac на базі Intel:** Можна запускати Stable Diffusion, але продуктивність буде нижчою. Рекомендується мінімум 8 ГБ ОЗУ.
- **ОС:** macOS Big Sur або новіша версія.

#### Крок 2: Налаштуйте оточення

Для Windows/Linux:

- **Встановіть Python:** Переконайтеся, що у вас встановлений Python 3.8 або вище.
- **Налаштуйте CUDA:** Якщо у вас NVIDIA GPU, встановіть останні драйвери CUDA і cuDNN для максимальної продуктивності.
- **Склонуйте репозиторій:** Завантажте популярний веб-інтерфейс, наприклад, [Automatic1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui) з GitHub.
- **Встановіть залежності:** Дотримуйтесь інструкцій у файлі README.

Зазвичай потрібно створити віртуальне оточення та встановити необхідні бібліотеки через pip:

1. git clone https\://github.com/AUTOMATIC1111/stable-diffusion-webui.git
2. cd stable-diffusion-webui
3. python -m venv venv
4. На Windows: venv\Scripts\activate або на Linux: source venv/bin/activate
5. pip install -r requirements.txt

Для macOS:

- **Встановіть Homebrew (якщо потрібно):** це допоможе керувати пакетами у macOS.
- **Встановіть Python:** використовуйте Homebrew для встановлення Python 3.8 або вище (наприклад, brew install python).
- **Оптимізована версія для Apple Silicon:** якщо у вас Mac з M1/M2, шукайте репозиторії або гілки, оптимізовані для Apple Silicon (наприклад, за запитом «stable diffusion webui mac» ви знайдете докладні інструкції).
- **Встановіть залежності:** дотримуйтесь тих самих кроків, як для Windows/Linux, з урахуванням специфіки macOS, зазначеної у README репозиторію.

#### Крок 3: Запустіть та експериментуйте

1. **Запустіть веб-інтерфейс:** після установки запустіть інтерфейс, виконавши відповідний скрипт (зазвичай щось на кшталт python launch.py).
