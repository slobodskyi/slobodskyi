#### What are Credits?

Ccredits are essentially the currency you use to generate images.

Think of them as tokens that power the AI image generation process. Each plan provides a certain allocation of credits, either monthly or daily.

#### How Credits are Used

Every time you generate an image using Diffus, a certain number of credits are deducted from your balance.

The number of credits consumed per image depends on various factors, including:

- **Model Used:** Different AI models may have different credit costs.
- **Image Resolution:** Higher-resolution images typically require more credits.
- **Number of Sampling Steps:** More sampling steps generally result in higher quality but also consume more credits.
- **Other Settings:** Additional settings and features may also affect credit usage.
- **GPU:** Using a dedicated GPU for faster processing will also require credits.

#### Estimating Your Image Output

Generating high-quality, photorealistic images uses more credits due to the complex settings required.

On average, you might get 1-3 detailed images per 10 credits.

- **Teaser plan (30 credits per day):** Approximately 30–90 images daily.
- **Basic plan (3,000 credits):** Approximately 300–900 images per month.
- **Plus plan (18,000 credits):** Approximately 1,800–5,400 images per month.
- **Pro plan (40,000 credits):** Approximately 4,000–12,000 images per month.

**For simpler images or fewer sampling steps, credit consumption may approach a 1:1 ratio.**

### Local: The Tech-Savvy Path (More Control)

Running Stable Diffusion on your own computer gives you complete control over your art—and the freedom to work offline.

This path is best for tech enthusiasts who aren’t afraid to tinker.

Here’s how to get started:

#### Step 1: Check Your System Requirements

For Windows/Linux:

- **GPU:** A dedicated NVIDIA GPU with at least 6GB VRAM (e.g., RTX 2060 or better). AMD GPUs might work, but support can be inconsistent.
- **RAM:** Minimum 8GB, with 16GB recommended for smoother performance.
- **CPU:** A modern multi-core processor (an i5 or higher is ideal).
- **Storage:** At least 10–20GB of free disk space for the model files and dependencies.
- **OS:** Windows 10/11 or a recent Linux distribution (like Ubuntu).

For macOS:

- **Apple Silicon (M1/M2):** Excellent native support via Metal—8GB of RAM is the baseline, though 16GB is better for intensive tasks.
- **Intel-based Macs:** You can run Stable Diffusion on the CPU, but expect slower performance. At least 8GB RAM is recommended.
- **OS:** macOS Big Sur or later.

#### Step 2: Set Up Your Environment

For Windows/Linux:

- **Install Python:** Ensure Python 3.8 or later is installed on your system.
- **Set Up CUDA:** If you have an NVIDIA GPU, install the latest CUDA and cuDNN drivers to take full advantage of GPU acceleration.
- **Clone the Repository:** Download a popular web UI like [Automatic1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui) from GitHub.
- **Install Dependencies:** Follow the repository’s README. Typically, you’ll set up a virtual environment and install required libraries using pip:

Example commands:

1. git clone https\://github.com/AUTOMATIC1111/stable-diffusion-webui.git
2. cd stable-diffusion-webui
3. python -m venv venv
4. venv\Scripts\activate (on Windows) or source venv/bin/activate (on Linux)
5. pip install -r requirements.txt

For macOS:

- **Install Homebrew (if needed):** This helps manage packages on macOS.
- **Install Python:** Use Homebrew to install Python 3.8 or newer (brew install python).
- **Optimized Branch for Apple Silicon:** If you have an M1/M2 Mac, look for repositories or branches optimized for Apple Silicon (search for “stable diffusion webui mac” for specific instructions).
- **Install Dependencies:** Follow similar steps as for Windows/Linux, adapting any macOS-specific instructions noted in the repository’s README.

#### Step 3: Launch and Explore

1. **Start the Web UI:** Once everything is installed, launch the interface by running the provided script (usually something like python launch.py).
2. **Access the Interface:** Open your browser and navigate to the local server (commonly at http\://localhost:7860).
3. **Customize and Experiment:** Enjoy full control—tweak model settings, test different prompts, and experiment with parameters offline.

Local installation is ideal if you have a powerful computer and strong technical skills, as it offers complete control and flexibility over your workflow.
