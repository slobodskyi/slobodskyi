Ця Полiтика конфiденцiйностi описує, як ФОП Слободський Олександр Миколайович (_далі — "Виконавець"_) обробляє персональні дані користувачів (_далі — "Користувачі"_) при використанні послуг Виконавця.

Оновлено: 16 січня 2025 року

## 1. Збір даних

1.1. Виконавець не збирає персональні дані безпосередньо.

Дані можуть оброблятися сторонніми сервісами, які Виконавець використовує для надання послуг, а саме:

1. Ahrefs Analytics: для аналізу трафіку сайту (_збирає тільки анонімізовані дані_).
2. Plata by Mono та Wayforpay: для обробки платежів.
3. SendPulse: для розповсюдження курсів через чат-боти.
4. Meta Pixel: для проведення маркетингових кампаній.

1.2. Дані, які можуть оброблятися через зазначені сервіси, включають: IP-адресу, технічну інформацію про пристрій, анонімізовану аналітику.

## 2. Використання даних

2.1. Виконавець використовує дані для:

1. Надання доступу до курсів та послуг.
2. Покращення якості обслуговування та роботи сервісів Виконавця.
3. Проведення маркетингових кампаній із використанням Meta Pixel.

## 3. Передача даних

3.1. Виконавець не передає персональні дані третім особам, за винятком cервісів, які Виконавець використовує для аналітики, обробки платежів або розсилки матеріалів.

3.2. Усі сторонні сервіси, які Виконавець використовує, відповідають стандартам безпеки та конфіденційності.

## 4. Файли cookie

4.1. Виконавець може використовувати файли cookie для аналізу трафіку (_через Ahrefs Analytics_) та для маркетингових кампаній (_з використанням Meta Pixel_).

## 5. Права користувачів

5.1. Користувачі мають право звернутися до Виконавця для:

1. Видалення будь-яких даних, які були отримані через сервіси.
2. Відмови від маркетингових кампаній або розсилок.

## 6. Безпека даних

6.1. Виконавець використовує технічні та організаційні заходи для захисту даних, які обробляються через сторонні сервіси.

6.2. Відповідальність за безпеку платежів лежить на платіжних сервісах (_Plata by Mono та Wayforpay_), які забезпечують захищене з'єднання.
